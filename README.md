# twenty-one

Хоррор-игра в трёхмерной стилистике с видом от первого лица. По сюжету игрок и его оппонент просыпается на зелёном карточном столе в заброшенной тюремной камере смертников. Вокруг полумрак, только приглушённая лампа над столом и старые телевизоры на стенах, которые транслируют белый шум. На одном из экранов висит таймер, отсчитывающий время на ход.
Суть игры строится на классических правилах оригинальной карточной игры. Каждый раунд открывается картой‑козырем, которая может изменить целевое количество очков, повысить или понизить силу удара током, подарить полезную карту или навредить оппоненту. 
Игроки ходят по очереди, и каждый может либо взять новую карту, либо остановиться. Затем сравнивается, кто ближе подобрался к целевому значению, не перебрав через край. Проигравший раунд получает одно деление на специальной шкале, похожей на спидометр, и его бьёт электрический стул с силой, равной текущей ставке. После каждого раунда ставка увеличивается на единицу. Тот, чья стрелка на шкале достигает максимума, проигрывает всю игру окончательно.
